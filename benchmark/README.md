# 受控评估摘要

这是一次探索性实验，评分来自模型裁判，不是真实读者研究。公开包提供摘要和评分标准，不包含论文全文、认证信息或本地执行日志；不能仅凭本目录完整重跑原始实验。

## 设计

GPT-6 sol high，Codex CLI 0.159.2。20 篇论文分别生成无 skill 和 v1 解读；每篇使用新上下文，相同全文提取文本和中文任务。关闭其他 skills、插件、shell、联网与记忆。skill 组显式获得入口及五个工作流参考文件。总计 40 份初始解读。

依据 10 篇开发集修订 v2，冻结后在另 10 篇留出论文生成解读，总计 50 份。裁判使用新上下文和匿名配对输入；另有 5 对顺序反转检查。评分标准在比较前冻结，九个维度加权为 100 分，另有错误扣分。阅读效率代理 R6 检查输出前 1200 个规范化文本字符对六个问题的回答情况，不等于真人阅读时间。

## 结果

| 比较 | 完整效用 U（100 分） | 前部信息 R6（100 分） |
|---|---:|---:|
| 无 skill → v1，20 篇 | 89.66 → 96.36 | 82.92 → 82.50 |
| v1 → v2，10 篇留出集独立重评 | 95.58 → 97.18 | 82.50 → 93.33 |

v1 完整效用平均增益为 6.70 分，配对 bootstrap 95% 区间 [5.30, 8.09]；v2 留出集平均增益 1.60 分，区间 [0.28, 2.93]。不同批次独立评分不可直接拼接成同一条绝对分数序列。

收益主要表现为计算与存储成本、DAG/并行通信和复现准备更加完整。v1 平均输出长度约增加 16%，因此完整性提升伴随阅读负担。v2 把核心机制和最小复现入口提前，改善 R6；但移除复现问题后，核心五项代理的变化分别为 −0.5 和 −2.0 分，区间均跨零。因此不能声称普遍提升核心算法的速读理解。

下游 FISTA 与 SCDM 的五个小型 NumPy 原型均通过各自 4 项检查；未观察到实现成功率提升，也没有复现论文全部图表、原始规模或分布式硬件结果。

## 限制与已发现问题

- 样本较小，经典论文可能已出现在训练数据中；每个条件仅单次生成。
- 同模型家族裁判可能偏好特定表达方式，匿名和顺序检查不能消除此偏差。
- 输入是 PDF 提取文本，图表、公式和版面信息可能丢失。
- v1 曾出现术语翻译、通信配置解释错误；v2 仍出现实验数值和实现细节遗漏。
- 没有真实读者计时，也没有足够证据证明完整科研复现能力提高。

下一步更有价值的验证是招募有相关基础的读者，随机分配等长解读，在限定时间后测试算法重建、边界判断和最小实现，并由独立专家核对关键公式与实验设置。
