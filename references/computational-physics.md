# 计算物理：公式如何变成算法，算法让什么物理可见

## 阅读提示

> 先说明改变了哪个物理计算环节，或获得哪项新的物理认识。围绕观测量，把模型、表示、关键推导与流程连起来，定位相对前作替换的具体步骤。THC/SVD/TT 等分解须说明对象、指标、秩、收缩次序与误差。优先解释同精度的成本收益、可计算体系扩大，以及是否真的带来新的物理结果，不只介绍缩写。

## 目标、表示与求解分层

连起：物理模型/哈密顿量 → 基组或网格/边界 → 波函数、密度、格林函数等表示 → 评估/采样 → 优化/自洽更新 → 内部代数求解 → 能量、力、谱、动力学或统计观测。

非电子结构工作按对象换链条：流体/场方程关注连续方程、守恒关系、离散通量、时间推进与代数求解；粒子模拟关注相互作用评估、邻域与时间积分；统计采样关注目标分布、提议/接受规则、权重、相关性与有效样本。不要把电子结构术语强套给它们。

各层可组合。VMC 描述随机评估，SR 定义参数更新，CG 可能是内部线性求解器；非线性 CG 又可直接优化，须看上下文。神经网络表示、选构型、轨道优化分别定位，不能把不同层的名称当成互斥替代。

“精确”相对于固定基组/指定哈密顿量，不等于连续极限或真实体系无误差。物理模型、基组/有限尺寸、压缩截断、迭代与采样误差分开。

## 找具体替换的一步

原表达式/操作 → 新表达式/操作 → 保留部分 → 误差/条件 → 收益。对角自能近似与完整准粒子方程应分清只改能量还是允许态改变，不能只说换求解器。

关键推导从定义出发，保留指标角色、积分/求和、单位、共轭；说明哪个等号因近似变成约等号。连到实际内核：积分如何变矩阵乘、FFT、稀疏作用、低秩收缩或局部求解。不要只重排原文公式，也不把近似当恒等式。

## 因子化专项问题

| 问题 | 要点 |
|---|---|
| 压缩什么 | 积分、轨道乘积、系数、响应/自能、算子或中间量；各指标物理含义 |
| 分成什么 | 因子形状、辅助秩/插值点/键维数；全局或局部；常驻什么 |
| 如何构造 | SVD、随机、插值、拟合或优化；setup、训练与刷新成本 |
| 如何使用 | 收缩顺序、最大中间量、省掉哪个高维求和或全矩阵 |
| 误差去向 | 如何影响能量、力、谱或长期动力学；理论、实验还是未知 |
| 如何扩规模 | r(ε,N)、局域性、筛选、谱隙/相关性条件；不能默认固定秩 |

SVD、THC、TT 不同义；任意 flatten 后的矩阵秩不能直接代替目标表示的秩。TT 各键秩可能不同。例：TT 核形状推得存储 Σ r_(k−1)n_k r_k；只有 n_k≤n、r_k≤r 才有 O(dnr²)，没有无条件消除维数灾难。THC-CCSD 则需区分积分与双激发振幅是否都被分解；某收缩的低阶不能冒充全部程序。[THC 原文](https://arxiv.org/abs/2111.11473)、[TT 光谱原文](https://arxiv.org/abs/1605.08422)。

## 结果优先级

方法论文通常先讲目标误差下的计算/存储下降，再讲可达体系、基组、时间或采样规模，然后物理验证和新科学结论。物理发现型论文先讲发现及证据。

“体系更大”要带电子/原子/轨道/格点数、基组/截断、秩、误差、硬件与预算。最大演示能力和旧法同预算比较不同；扩大演示不能自动量化成加速。形式 O(N) 依赖固定秩/局域半径时明确保留，检查 setup 和其他阶段。

区分复现已知结果、验证算法、进入困难参数区、新物理规律。新算法不必有新物理，没有就说明；新物理需对照、有限尺寸/基组/时间步收敛、统计误差或独立方法支持。采样比较同误差的有效独立样本成本；能量准确不自动证明力、应力和激发同样准确。不设跨体系统一精度阈值。

新变分更新/预条件决定贡献时加 [数学模块](mathematics-and-optimization.md)；分布式能力是主张时加 [并行模块](parallel-and-distributed.md)。局部低秩不能自动消除 FFT/正交化/全局归约的通信。无实现证据的方案标推导。

复现先验证小体系公式/观测量，再固定精度对比替换阶段和总时间，最后扩规模。设置来自论文，读者建议单独标明。
