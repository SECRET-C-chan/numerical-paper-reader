# 按贡献证据路由

## 摘要中的相似因子

提取以下语义因子作为阅读笔记；一般不把整张路由表输出给读者。

| 因子 | 提取内容 | 避免误判 |
|---|---|---|
| 目标 | 数学解/保证、物理观测/认识、时间/吞吐/资源 | 应用背景不等于主要贡献 |
| 对象 | 向量、块子空间、算子、张量、波函数、粒子、tile/分片 | 提取角色，不能只摘关键词 |
| 变化 | 更新/证明/近似/表示/收缩顺序/布局/调度 | “使用 X”不等于“创新 X” |
| 基线 | 被替换的步骤、被放宽的限制 | 缺失时查引言，不虚构传统方法 |
| 证据 | 定理、误差/成本、观测量、体系规模、效率/消融 | 承载主结论的证据决定重心 |
| 瓶颈和条件 | 病态、秩/精度、物理近似、同步/带宽/内存 | 区分被解决的障碍与背景 |

“相似因子”指贡献的语义特征，不是词频、分类数量或未经计算的余弦距离。不输出虚构概率；用“主证据明确 / 次要支持 / 材料不足”说明依据。

## 判断顺序

1. 用户意图确定阅读视角。用户要通信而论文只给数学算法时，可能的分布式设计标为推导；作者贡献主线与用户视角可以不同。
2. 摘要初选：目标和变化提出候选，证据确认主线。至少用“变化＋目标或证据”解释理由，不能单关键词命中。
3. 正文复核：贡献段、主公式/算法、主定理或结果图可推翻初判。没有摘要就从这些位置建同样记录；只有摘要就保持暂定。
4. 主线承担开头和主要篇幅，辅线只补理解贡献所需。两条证据链不可分时保留双主线；三类均有独立充分证据才再展开第三条。
5. 反事实检查：去掉哪一个新更新、近似或调度，主贡献就不成立？优先解释它。没有消融时，这只是阅读组织上的判断，不能说已证因果。

数学主线：新的求解、表示、预条件或定理承载贡献；物理主线：从物理模型到观测量的步骤改变，或新物理证据；并行工程主线：改布局、映射、依赖或调度并以性能为主要证据。分布式理论另看 LOCAL/CONGEST 等模型及轮数/消息界，不能强求机器实验。

## 容易误分的组合

| 信号组合 | 重点 | 不能推出 |
|---|---|---|
| DFT 中新的块特征求解/预条件 | 数学主，物理补矩阵来源与精度 | 新物理发现 |
| THC/TT 能量或谱计算、固定误差下扩规模 | 物理＋必要的数学分解 | 固定秩、整个程序同一低阶 |
| 沿用物理算法，重排多 GPU 任务提高效率 | 并行主，物理补正确性 | 新物理模型 |
| decentralized optimization 有收敛和轮数界 | 数学＋分布式理论 | RDMA 带宽、GPU 效率 |
| 张量逼近定理，无物理观测 | 数学理论 | tensor 必属物理 |
| 新相或谱特征，算法成熟 | 物理发现，控制与收敛证据 | 必有复杂度下降 |
| 流水 CG 的舍入误差分析/残差修复 | 数值分析主，并行辅 | parallel 词多即并行主 |
| 多分区或期刊名与内容不一致 | 按目标、变化、证据重判 | 首分区决定内容 |

只有摘要时写“根据摘要，重点似乎在……；需要正文确认……”，给机制和最重要的未知项，不给论文质量总分。真实论文案例与来源见 [v3 依据](research-basis-v3.md)。
