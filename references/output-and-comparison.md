# 用读者能复述的语言组织解读

## 首段与展开

先给一个具体判断，不以书目信息、大符号表或学科标签开头。关系是“旧瓶颈—实际改变—为什么有用—关键条件”，不是每篇都照填同一句。复杂贡献可用两句，不强迫所有研究只有一个巧思。

以下是写法示例，不能当成任意目标论文的事实：

- 数学：与其保存展平参数的一整个大预条件矩阵，这个方法按参数各轴保存较小的梯度统计矩阵，再从两侧修正更新方向；节省的是相对全矩阵版本的状态，矩阵幂仍需付费。
- 物理：这里不仅压缩积分，也压缩双激发振幅，从而改写最昂贵的收缩；可达规模随因子秩与目标能量误差变化，不能只记一个形式标度。
- 并行：它多存几份输入，让不同层各做一部分乘积，最后合并；减少通信的代价是增加每进程内存，而不是减少矩阵乘法的算术指数。

这些例子对应 [调研案例](research-basis-v3.md)。面向实际论文必须回到原文查条件与定量结果。

随后按主线组织，而非固定章节：

| 主线 | 常见展开顺序 |
|---|---|
| 数学算法 | 明确问题 → 对象/状态 → 更新与预条件 → 与基线逐步差异 → 计算/存储及保证 |
| 数学理论 | 旧命题与限制 → 新结论/假设 → 关键构造或证明转折 → 能用在哪、不能推出什么 |
| 物理方法 | 观测目标 → 模型/表示 → 公式中的替换 → 算法执行 → 同精度成本/可达规模 → 科学意义 |
| 物理发现 | 新认识 → 关键观测与对照 → 数值/模型可靠性 → 支撑结论的方法和边界 |
| 并行实现 | 有条件的效率/时间结果 → 分块/所有权 → 资源映射 → 依赖/流水线 → 通信/内存权衡 |
| 分布式理论 | 模型与新界 → 局部信息 → 通信构造 → 正确性/下界 → 适用边界 |

只补必要背景；术语首次出现用一句白话解释作用。公式紧接它回答的问题；表格用于对比或对象映射，图用于依赖/布局。没有解释作用就不画。避免重复开头，避免段段“本文提出”。

局部追问如“b 向量是什么”“为什么这个步长”“哪块交给哪个 GPU”直接解释定义、角色、依赖和依据，不重新输出整份论文报告。速读不等于编出未知的实现；精读也不等于逐章翻译。

## 多篇比较

先对齐问题、输出、误差、可访问 oracle、物理模型/基组或机器预算，再比较。不能对齐的项说明原因，不强排名。采用最相关的行：

| 维度 | A | B | 可比性与判断 |
|---|---|---|---|
| 目标与边界 | 定义 | 定义 | 同一任务吗 |
| 主要对象与表示 | 形状/存储 | 形状/存储 | 改了哪一层 |
| 一步更新或关键替换 | 操作 | 操作 | 继承/新增及原因 |
| setup/每步/到精度总成本 | 条件式/实测 | 条件式/实测 | 同误差口径吗 |
| 存储/临时工作区 | 全局/每进程 | 同左 | 复制/秩/缓存差异 |
| 保证或观测量 | 定理/实验 | 同左 | 条件、范数、统计一致吗 |
| 并行与通信（相关时） | 布局/依赖/总量 | 同左 | 同资源与质量吗 |
| 可达能力与复现 | 规模、材料、验证层次 | 同左 | 尚缺什么 |

综述围绕问题、机制和分歧综合；同一工作的预印本、期刊版和代码关联，不能重复计票。谱系依据更新式、机制与明确引用，不能只看标题/年份。没有统一成本权重，不造总分与唯一赢家。

## 证据、判断与下一步

核心公式、定量、创新与限制旁给原文定位。长综述可建证据账本，短解读直接嵌入；内部检索 ID 不是原文位置。将作者声称、定理/实验、代码、分析者推导分开；来源类型不等于本次独立验证程度。

复现请求连接明确小问题、输入参数、核心操作、参考对象和判定量。分别说明算法原型、论文图表、原规模/硬件复现的支撑程度；未运行不能写成成功。研究建议落实到能区分机制或假设的一项验证，别凭几篇论文宣布领域空白。

仅在用户要求程序处理时给 JSON，建议包含 problem、objects、change、costs、evidence、limitations 及按需的 physics/parallelism。路由标签不是必填交付物；未知值用 null 与原因，不用 0 假装测量。
