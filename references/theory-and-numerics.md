# 理论保证与数值可信度

## 定理卡

对支撑核心贡献的定理填写下表；辅助引理只记录与主结果有关的依赖。

| 字段 | 内容 |
|---|---|
| 定位与角色 | 版本、定理编号；正确性/可行性/稳定性/收敛/复杂度/下界 |
| 对象与输出 | 迭代点、平均点、best iterate、随机选点、物理量、近似解 |
| 假设 | 可行域、凸性/强凸性、光滑性、正则性、谱、独立性、噪声、初值、参数范围 |
| 结论 | 精确表达式、范数、误差定义、常数与量词，不把重要项藏进 O(·) |
| 概率口径 | 确定性、期望、高概率 1−δ、几乎处处；对谁取随机性 |
| 有效范围 | 局部/全局、渐近/有限步、维度/网格/条件数依赖 |
| 证明主线 | 关键不变量或势函数、决定性引理、闭合递推关系、作者新引入的论证 |
| 核查程度 | 只读陈述/核查主线/检查关键代数/独立重证；不要笼统写“证明正确” |
| 实践差距 | 哪些假设在代码或实验中未满足？参数是否需要未知常数？ |

解释关键公式时交代“量的含义、公式负责哪一步、为什么需要、改变它会影响什么”。用短证明纲要展示依赖，避免只逐行翻译。

## 优化与算法复杂度的边界

- “收敛”可能只意味着残差趋零、目标值收敛、某个子序列收敛或收敛到驻点；逐一确认，不升级成唯一全局最优解。
- 非凸算法的 global convergence 常指从某类任意初值获得驻点性质，并不自动等于找到 global minimum。
- 对比 O(1/k)、O(1/k²)、线性率时必须对齐误差量、假设、每步 oracle、迭代输出以及常数。期望界和高概率界不能直接按阶排序。
- 声称“最优”时确认：相对哪个问题类、哪个 oracle/机器模型、确定性还是随机算法、哪个精度标准，是否有匹配下界；下界的计算/内存约束是否相同。
- 一次梯度、Hessian-vector product、投影或近端调用不是固定成本。子问题仅近似求解时，记录内层容差、失败概率、误差累积和总内层工作量。
- Õ(·) 要说明隐藏的对数参数；多项式界要区分算术操作次数与输入位长/精度的 bit complexity。对非强多项式算法检查数值大小依赖。

## 从收敛界到 ε 成本：教学例

以下仅为读者推导示范，不代表某篇论文结果。假设原文已经证明非负误差 e_k ≤ C/k^q，q>0，C 不随 k 变化，则满足目标 e_k≤ε 的充分迭代数可取

\[
k_\varepsilon=\left\lceil (C/\varepsilon)^{1/q}\right\rceil.
\]

若 e_k≤Cρ^k，0<ρ<1 且 0<ε<C，可取

\[
k_\varepsilon=\left\lceil\log(C/\varepsilon)/(-\log\rho)\right\rceil.
\]

若每步成本 c_k 不同，写 setup+Σ_{k<kε} c_k，而非无依据使用 kε×常数。C、ρ 可能依赖维度、条件数、网格、初值或处理器数，不能消掉这些依赖。上述是由上界推出的充分条件，不是实测次数或必要下界。

## 数值误差审查

从实际输出向前追踪误差来源：物理/统计建模 → 空间时间离散 → 低秩/截断/采样近似 → 迭代求解 → 浮点运算。是否可以相加须由误差传播分析支持，不能默认所有误差线性独立。

重点区分：

- 前向误差、后向误差、残差与条件数。小残差不能单独保证小前向误差。
- 一致性、稳定性与收敛。使用它们之间的定理关系时检查该问题是否满足相应前提。
- 理论 exact arithmetic 与实际有限精度。消去、正交性损失、病态线性系统、归约顺序、混合精度可能改变实际行为。
- 网格/时间步收敛与迭代收敛。求解到远小于离散误差的容差可能浪费成本；放宽容差可能改变观测量。
- 近似加速、截断或压缩节省的成本与引入的偏差/不稳定性。是否提供精度可控的参数或误差估计？
- 数值重现和逐位一致不同。并行浮点归约次序改变不必然使方法失效，但需要观察量或误差容限依据。

## 如何提出有效批评

把问题写成“证据 → 受影响的主张 → 条件化结论 → 能验证的下一步”。例如：原文只证明平均迭代点的期望目标差；代码输出最后一点；因此该定理尚不足以支持代码输出的同等保证；应查对应附录或比较两种输出。

不因缺少不相关定理否定软件论文，也不因理论论文没有性能 benchmark 判其无效。反例只能针对明确命题和假设；先检查是否满足假设，再说反例推翻了什么。
