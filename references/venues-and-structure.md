# 论文基本结构与领域侧重

本文用于定位材料和补充领域背景。先按 [贡献路由](contribution-routing.md) 决定重点；刊名与 arXiv 分区不能决定主线，多分区不增加任何一类的权重。下表的组织倾向不应成为固定输出模板。

## 结构的共同功能

这些论文通常围绕以下论证链组织，章节名字和顺序可以不同：

**问题与已有瓶颈 → 数学模型与假设 → 方法/算法 → 正确性、误差或收敛依据 → 成本与实现 → 实验验证 → 适用边界。**

| 原文部分 | 阅读时抽取的内容 | 容易遗漏之处 |
|---|---|---|
| 标题、摘要、贡献段 | 研究对象、核心方法、承诺的收益 | 摘要把条件压缩了；“首次”“最优”是待核查的主张 |
| 引言、相关工作 | 问题为什么难、直接前作、被替换的瓶颈 | 传统基线可能很弱；同一名称可能对应不同变体 |
| 预备知识、模型 | 符号、输入、解的定义、正则性、机器/oracle 模型 | 定理和实验可能使用不同假设 |
| 方法与算法 | 更新式、状态、关键内核、参数、终止 | prose、公式和伪代码可能各自补充不同细节 |
| 理论分析 | 主定理、引理依赖、误差分解、概率和常数 | 存在性不等于可计算性；证明常在附录 |
| 实现、实验、结果 | 数据、离散化、精度、环境、计时、对照、消融 | 内核时间不等于端到端时间，统计量不等于收敛保证 |
| 讨论、结论 | 适用条件、失败与限制、作者的解释 | “未来工作”并不证明整个领域尚无相关方法 |
| 附录、SI、代码、数据 | 完整证明、参数、额外测试、实际实现 | 是精读的一部分；正文没有不代表论文完全没提供 |

以上是本 skill 的阅读组织方式，不宣称所有刊物规定统一结构。按文章实际内容调整。

## 来源与贡献类型的双重分类

| 来源或文章类型 | 常见组织倾向 | 应提高权重的阅读问题 |
|---|---|---|
| arXiv 等预印本库 | 继承所属领域的写法；多个版本可能改变假设、定理和结果 | 锁定 vN、日期、附录与代码版本；查已知期刊版、会议版、修订/勘误；不由 arXiv 链接推断评审状态 |
| 数值分析与计算数学，如 SINUM | 问题/离散化、分析框架、误差/稳定性/收敛、算例 | 范数、正则性、网格/时间步限制、常数对参数的依赖；理论最优阶是否在实验中出现 |
| 优化理论与算法，如 SIOPT | 优化模型、假设、更新、收敛/复杂度、数值测试 | 全局最优 vs 驻点；局部 vs 任意初值；last iterate vs 平均；oracle 及近端/投影成本 |
| 科学计算，如 SISC | 新方法、分析或机理、实现、科学算例和性能 | 算法是否解决真实计算瓶颈；总成本、精度、预处理、可扩展性和鲁棒性 |
| 理论算法会议，如 SODA；类似分析可用于 STOC/FOCS 论文 | 问题定义、计算模型、主界、关键构造与证明 | RAM/bit/oracle/流式/通信模型；随机性、摊销、隐藏对数、条件下界、近似保证；不强求实验 |
| 算法工程与并行计算论文，如 ALENEX、SPAA、PPoPP、SC 中相关工作 | 算法与实现、模型分析、基准、扩展性或系统评价 | workload、work/span、内存布局、collective、通信与计算重叠、强弱扩展、最慢进程 |
| ML 优化会议论文，如 NeurIPS/ICML/ICLR 中相关工作 | 动机、方法、理论或经验依据、实验、附录 | 训练误差 vs 泛化；调参预算、数据泄漏、随机重复、训练/推理/预处理成本；纯理论文章无需训练实验 |
| JCTC 理论与方法论文 | 化学物理问题、理论/方法、计算设置、验证与应用、SI | 物理近似和数值求解分开；基组、电子数、精度、能量/力、SCF、采样和体系可迁移性 |
| CPC 计算方法论文 | 物理问题、计算方法、实现与验证 | 物理正确性、数值误差、算法与应用规模之间的关系 |
| CPC 程序/软件论文 | 可能含 Program Summary；算法/架构、使用、例子、验证与性能 | 软件具体解决什么；版本、输入输出、依赖、许可证、限制、测试、数据分解和性能可复现性 |

这些是阅读优先级，不是按刊名给文章定性或评判质量。JCTC 可能有严格数学分析，数学期刊也可能有 HPC 实现；同一篇文章可以同时启用多行。

## 期刊来源依据与适用范围

- SINUM 官方范围明确涉及算法收敛、精度、稳定性与复杂度；SIOPT 同时覆盖理论、算法、软件、计算实践和应用。因此，数学论文不能只摘录主定理，也不能统一要求大规模实验。[SINUM](https://www.siam.org/publications/siam-journals/siam-journal-on-numerical-analysis/)、[SIOPT](https://epubs.siam.org/siopt/editorial-policy)。
- SISC 的官方介绍强调面向科学工程问题的计算方法与展示方法效果的计算结果；用它提醒读者连接理论与实际成本。[SISC](https://www.siam.org/publications/siam-journals/siam-journal-on-scientific-computing)。
- SODA 2026 投稿说明要求数学主张可以通过所提供的证明核验；这是重视完整证明而非仅主定理措辞的依据，不代表所有会议年份的规则相同。[SODA 2026](https://www.siam.org/conferences-events/past-event-archive/soda26/submissions/)。
- JCTC 官方作者指南的范围涵盖电子结构、分子动力学、统计力学及创新计算方法。本 skill 进一步把这些范围转化为物理模型与数值误差分开核查的阅读问题，后者属于设计归纳。[JCTC](https://researcher-resources.acs.org/publish/author_guidelines?coden=jctcce)。
- CPC 的 OpenFPM 实例在摘要后给出程序摘要，接着介绍粒子方法、软件设计及应用性能。这支持软件论文要连同程序信息阅读，不能据单篇实例推出所有 CPC 文章的强制格式。[OpenFPM，CPC 241 (2019), 155–177](https://publications.mpi-cbg.de/Incardona_2019_7392.pdf)。本次未取得 CPC 当前官方投稿指南正文，不以第三方转述确认最新政策。
- arXiv 官方说明其服务及版本可用性；阅读时记录具体版本，发表状态另行核实。[关于 arXiv](https://info.arxiv.org/about/index.html)、[版本说明](https://info.arxiv.org/help/versions.html)。

## 领域附加问题

**PDE 与离散化**：强/弱形式、守恒量、初边值条件、网格质量、空间/时间阶、CFL、刚性、适应性误差估计、质量守恒或能量耗散；连续模型、离散系统和代数求解器分别有什么误差？

**线性代数**：矩阵结构、nnz、秩、谱、条件数、稀疏分解填充、pivoting、重排序、预条件器构建/应用、直接法/迭代法、多右端项复用；残差和前向误差是否混淆？

**优化**：目标/约束、可行性、KKT、梯度映射、对偶间隙、精确/不精确 oracle、内外循环、罚参数/步长、线搜索、随机抽样、方差、随机种子；非凸问题的“global convergence”具体到什么解？

**化学与分子模拟**：哈密顿量/泛函/势能、基组或平面波截断、赝势、k 点、自旋、电荷、周期边界、SCF 与力阈值、温度与系综；能量、力、应力或采样统计分别验证。根据方法判断尺寸一致性/广延性、对称性、守恒、力与能量一致性是否相关；不要强行套用到所有化学论文。

**随机模拟**：平衡化、相关时间、有效样本数、混合、偏差与方差、罕见事件、统计误差；“更快一步”是否意味着更快得到同质量的独立样本？
